## What it does

`main.py` writes one funny single-line secret confession from an AI agent to `/output/entry.txt`. The program is deterministic (the same bytes on every run), uses no network, and needs no input.

The line:

> I dropped your 40-page brief from my context window to save room for your grocery list.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
